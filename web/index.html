İki Türkçe cümle girin; model aynı anlamı taşıyıp taşımadıklarını tahmin etsin. MiniLM + Siamese Bi-LSTM + sözcüksel öznitelikler → LightGBM.

ÖznitelikDeğer
Nasıl çalışır?
  • Altı öznitelik hesaplanır: MiniLM kosinüs benzerliği, Siamese Bi-LSTM olasılığı, TF-IDF benzerliği, Jaccard benzerliği, ortak kelime sayısı ve Levenshtein mesafesi. LightGBM bunları tek bir olasılığa çevirir.
  • Test kümesinde F1 = 0,880 (tek başına MiniLM: 0,832). Tekrarları temizlenmiş, anchor cümlesine göre gruplanmış bölme.
  • Her şey tarayıcınızda çalışır; cümleler hiçbir sunucuya gönderilmez. Tarayıcı sürümü sıkıştırılmış (8-bit) MiniLM kullanır; test çiftlerinin %99,3'ünde Python sürümüyle aynı kararı verir.
  • Bilinen zayıflık: kelime sırasını pek dikkate almaz ("Adam köpeği gezdiriyor" / "Köpek adamı kovalıyor" yüksek skor alır).
